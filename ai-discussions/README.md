# AI 讨论笔记

> 这个目录用于存放与 AI 讨论各个领域知识时产生的文档、方案、设计等产物。

## 这是什么

项目所有者经常在此目录下与 AI 讨论跨领域的知识——可能是硬件设计、算法方案、架构思考，也可能是任何其他领域的探讨。讨论过程中产出的文档（HTML、Markdown、PDF 等）都会归档到这里。

## 分类规则

**按领域/主题分门别类存放**，每个主题一个子文件夹，文件夹名用简洁的中文描述领域名称。

当前已有分类：

| 文件夹 | 领域 | 说明 |
|--------|------|------|
| `电机驱动与控制/` | 电机控制、驱动电路 | RC380 / DRV8701 相关的电流环方案、布局与滤波设计等 |

## 目录结构

```
ai-discussions/
  README.md                 ← 你在这里
  电机驱动与控制/
    RC380_DRV8701_布局与滤波设计.html
    RC380_电流环方案.html
    RC380_电流环方案_v2_优化版.html
  <新领域>/                  ← 未来新增领域时创建新文件夹
    ...
```

## 新增内容时的注意事项

1. **先确认领域归属**：新文档应放入对应的领域子文件夹；若领域不存在，先创建文件夹。
2. **文件命名清晰**：文件名应能体现内容主题，如 `RC380_电流环方案_v2_优化版.html`。
3. **版本迭代保留历史**：同一主题的多个版本（如 v1、v2 优化版）都保留，便于追溯演进过程。
4. **与项目代码无关**：此目录下的内容**不是** Spark Vault 应用的源代码，仅为知识讨论产物，不影响应用构建与运行。
