1. 核心参数与设计约束

参数数值对电流采样的影响
额定电压DC 9V低压系统，无需隔离，低侧非隔离采样最优

堵转电流< 14.4 A极高！ 动态范围 33:1（14.4A / 0.43A）
持续工作电流约 3–5 A（赛道负载估计）决定采样电阻长期发热与驱动选型

⚠️ 最大挑战：33:1 的动态范围

同一通道既要分辨 0.43A（空载微调），又要扛住 14.4A（堵转/起步）。12-bit ADC @3.3V 基准 ≈ 0.806mV/码，设计的核心就是：让 14.4A 尽量占满量程、又不削顶。

2. 采样电阻选型（v2 核心修正）

2.1 三方案定量对比（增益均取 20 V/V）

  • 推荐阻值：10 mΩ。堵转压降 144mV，相对 9V 母线损耗仅 1.6%，可忽略。
  • 功率额定：P = 14.4² × 0.010 ≈ 2.1W。堵转是瞬态（有硬件限流兜底），选 3W 合金电阻即可；长期 3–5A 运行时功耗仅 0.09–0.25W。
  • 型号推荐：Vishay WSLP2512L1000FEA（10mΩ, 3W, TCR ±75ppm/°C）或 Bourns CSS2H-2512R-L100F。

✅ 开尔文接法（勘误）：WSLP/CSS 系列是两端子封装，正确做法是开尔文焊盘布局——采样走线从电阻焊盘内侧单独引出，不与主电流路径共用铜箔。两端子+开尔文走线在 15A 内精度足够；若要真四端子，选 Isabellenhütte BVR/BVT 系列（成本高，比赛无必要）。

3. 电流检测放大器

  • 所需增益：G = 3.0V / 0.144V ≈ 20.8 → 取标准增益 20 V/V，@14.4A 输出 2.88V，留 0.4V 防饱和余量。
  • 首选：INA181A1（20 V/V）。
    • 关键指标是输入失调电压：INA181 Vos ≤ ±150µV → 等效电流误差 150µV/10mΩ = 15mA（空载的 3.5%，可接受）。
    • v1 选的 INA180 Vos ≤ ±500µV → 等效 50mA 误差（空载的 12%），不建议。
    • 带宽 350kHz，远高于电流环需求，OK。
  • 更优解：直接用 DRV8701 内置采样放大器（增益固定 20 V/V，SO 引脚输出）。
    • 省掉外置 INA181，BOM −1，且与驱动布局天然紧凑。
    • 外置放大器仅在用 TB67H450 或纯分立 MOS 时需要。
  • 输入端滤波：采样电阻到放大器输入串 10Ω×2 + 差模 1nF（fc≈8MHz），抑制射频级噪声，不影响信号。

4. 滤波与采样时序（v2 核心修正）

4.1 输出级 RC：fc 必须跟随 PWM 频率设计

  • v1 的 47Ω+2.2nF（fc≈1.5MHz）对 kHz 级 PWM 电流纹波完全无效，只是心理安慰。
  • 设计规则：fc 取电流环带宽的 2–3 倍、PWM 频率的 1/3 以下，单级 RC 对 PWM 基波才能获得 ≥10dB 衰减。
  • 推荐取值（PWM = 17kHz，避开可闻频段）：3.3kΩ + 10nF C0G → fc ≈ 4.8kHz。
    • 对 17kHz 纹波衰减 ≈ 11dB，配合 4.2 节同步采样后残余纹波可忽略。
    • 对 1–2kHz 电流环穿越频率仅引入 11–23° 相移，不影响环路稳定性。
    • 3.3kΩ 源阻抗下 STM32 ADC 采样周期设 239.5 cycles，10nF 电容兼作采样保持电荷桶。
  • 其他 PWM 频率换算：C = 10nF 固定，R ≈ 1/(2π·fc·C)。如 PWM=10kHz 取 fc≈3.3kHz（R=4.7kΩ）；PWM=20kHz 取 fc≈6.8kHz（R=2.2kΩ）。

⚠️ 17kHz PWM 的纹波量级（为什么同步采样是必需而非可选）

380 电机电感很小（约几十~200µH），按 L=100µH、D=0.5 估算：ΔI = V·D(1−D)/(L·f) ≈ 9×0.25/(100µH×17kHz) ≈ 1.3A 峰峰值纹波。随机时刻采样会落在纹波任意相位，读数剧烈抖动。只有在下管导通中点采样（对称三角波中点电流 = 平均电流），才能从时序上根除纹波影响。

4.2 PWM 同步采样（低侧采样的必修课）

⚠️ 低侧采样只在下管导通时有电流流过。续流（上管体二极管/同步整流）期间采样电阻电流为 0，随机时刻采样会得到系统性偏低、且随占空比抖动的读数。

  • 做法：用定时器中心对齐 PWM，在下管导通区间的中点触发 ADC 注入转换（STM32：TIM1 TRGO → ADC 注入通道）。
  • 采样窗口核算（17kHz）：周期 58.8µs，5% 最小占空比 → 导通 2.9µs；扣除边沿振铃 ~1µs 后开始转换，12-bit @21MHz ADC 约 1.2µs 完成，窗口足够。
  • 低占空比时下管导通时间过短，需限制最小占空比（如 5%）或在该区间改用上次有效值。

4.3 电机端源头吸收（保留 v1，仍是最重要的 EMI 手段）

  • 电机两引脚间并联 100nF C0G，每个引脚对电机外壳各接 100nF（Y 电容布局），电容引线越短越好，直接焊在电机端子上。
  • 必要时在电源入口串 磁珠（600Ω@100MHz） 隔离电机噪声与逻辑电源。

5. 驱动与堵转保护（v2 核心修正）

  1. 驱动选型：
    • 首选 DRV8701（外置 MOS，栅极驱动电流可调）：堵转 14.4A 由外置 MOS 扛，且内置 20V/V 采样放大器。
    • 外置 MOS 选 AON6244 / IRLR7843（Rds(on) < 5mΩ，DFN5×6）。
    • TB67H450（内置 MOS，峰值 4.5A）仅适合严格限流场景，不推荐用于可能堵转的驱动轮。
  2. 硬件逐周期限流（必须有）：
    • DRV8701 的 VREF 引脚设定斩波阈值：I_chop = VREF / (G × R_sense)。例：VREF = 1.0V → I_chop = 1.0 / (20 × 0.010) = 5A 逐周期限流，堵转瞬间电流被硬件钳住，软件 50ms 根本来不及的事交给它。
    • VREF 可由 MCU DAC 输出 → 软件可调限流，起步给大限流、巡线给小限流。
  3. 软件后备保护：电流 > 12A 持续 > 50ms → 关 PWM 并报错（防硬件限流失效）；配合温度估计（I²t 积分）做电机热保护。

6. PCB 布局要点

  1. 开尔文走线：采样电阻焊盘内侧单独引出差分对到放大器输入，远离 MOS 开关节点（SW）和栅极回路。
  2. 星型接地：功率地（采样电阻 GND、母线电容 GND）与信号地（放大器、MCU）单点汇接于母线电容负极；ADC 参考地走模拟地平面。
  3. 母线电容：驱动入口 ≥ 220µF 电解 + 100nF 陶瓷紧贴 H 桥；9V 母线预留 SMBJ12A TVS 吸收制动回灌电压尖峰。
  4. 热设计：采样电阻与 MOS 下方铺铜 + 过孔阵列散热；电阻远离放大器输入端，减少热梯度引起的温漂。

7. 软件策略

  • 硬件过采样：STM32 ADC 开 16× 过采样 → 有效约 14 bit；空载 107 码 → 等效 ~428 码，0.43A 区间分辨率 < 1mA。16× 过采样已含平均效果，可与 4.1 节 RC 滤波叠加。
  • 零点自校准：上电时 PWM=0 采 32 次取均值存为零点偏移，消除放大器失调的批次差异。
  • 分段 PID：低速区（<1A）高 P 增益保证响应；重载区（>5A）降增益防超调。
  • 电流环带宽：目标 1–5kHz 足够有刷电机力矩控制；不必追求更高，否则噪声主导。

💡 总结：v2 相对 v1 的核心收益——同样 12-bit ADC，空载分辨率翻倍（53→107 码）、失调误差降为 1/3（50→15mA）、PWM 纹波真正被滤掉、堵转由硬件逐周期限流兜底。BOM 成本基本持平（DRV8701 方案反而省掉外置放大器），完全满足智能车精准速度环 + 力矩限制的需求。
