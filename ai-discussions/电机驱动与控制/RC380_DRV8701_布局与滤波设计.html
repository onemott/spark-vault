DRV8701 + 17kHz PWM · 走线布局与滤波电路设计指南

适用对象：RC380 有刷直流电机（9V / 堵转 14.4A）电流环功率板。本文与《RC380 电流环方案 v2》配套，聚焦两件事：PCB 怎么走线布局、各级滤波怎么设计。核心器件：DRV8701（内置 20V/V 采样放大器 + VREF 斩波限流）+ 10mΩ/3W 采样电阻 + 4× AON6244。

✅ 分区三原则

  1. 功率区（母线电容、H 桥、采样电阻、电机端子）全部挤在一侧，大电流环路面积最小化；
  2. 驱动区（DRV8701）紧贴 H 桥，栅极走线 < 15mm；
  3. 逻辑区（MCU、ADC、通信）在对侧，中间用地平面隔开，任何大电流不走逻辑区下方。

2. 高 di/dt 功率环路：EMI 的源头控制

17kHz PWM 下每个开关沿都有 ns 级的 di/dt，环路电感 × di/dt = 电压尖峰，直接决定 MOS 应力和辐射水平。

2.1 两条关键环路

  • 换流环路（最重要）：母线高频电容(100nF) → 上管 → 电机 → 下管 → 采样电阻 → 回到电容负极。环路面积必须最小，方法是在每个半桥的上管漏极到下管源极之间，紧贴 MOS 放一颗 100nF 0603 陶瓷（"半桥贴身电容"），让高频换流电流在局部闭合，不去骚扰远处的电解电容。
  • 栅极驱动环路：DRV8701 GH/GL → 栅极 → 源极 → 回到芯片 GND/SH。GH 与对应 SH1、GL 与 PGND 尽量成对走线（上下层或并行），宽度 ≥ 0.5mm，长度 < 15mm，禁止跨分割平面。

⚠️ 三个常见翻车点

  1. 采样信号走了功率路径：SP/SN 若从电阻焊盘外侧或功率铜箔上取电，焊点/铜箔的毫欧级电阻 × 14.4A = 几十 mV 误差，直接淹没信号。必须 Kelvin 从焊盘内侧单独引出。
  2. 栅极回路穿过电机相线下方：SH1/SH2 是 dv/dt 最猛的节点，其铜皮不要铺到驱动信号回流路径上。
  3. 母线电容放太远：220µF 离 H 桥超过 20mm，换流尖峰立刻上来。贴身 100nF + 近距电解，缺一不可。

3. 接地策略：一个星型点定乾坤

  • 四层板推荐叠层：L1 信号+功率 / L2 完整地平面（不分割！） / L3 VM 电源面 / L4 信号。地平面完整比"分割模拟地数字地"更重要。
  • 两层板做法：功率地（母线电容负极、Rsense 的 GND 侧、TVS）走底层粗铜；逻辑地（MCU、DRV8701 GND、滤波电容地）单独一片；两片地在 Rsense 的 GND 端焊盘处单点汇接。这样大电流压降全部落在功率地铜箔上，采样和 ADC 的参考点干净。
  • DRV8701 散热焊盘（PowerPAD）：必须焊接到大面积 GND 铜皮 + ≥9 个 0.3mm 过孔阵列到底层散热。它同时是芯片的电气地，就近接逻辑地。
  • ADC 参考：MCU 的 VSSA/VREF− 接逻辑地，滤波电容（10nF）的地脚直接落到 MCU 旁的逻辑地，不要落到功率地。

5. 滤波电路设计（17kHz 参数已锁定）

5.1 全链路滤波一览

电机端子 ──[100nF×3 源头吸收]──► H桥 ──[半桥贴身 100nF]──► VM ──[220µF+100nF]──► 9V
                                          │
 Rsense ──[10Ω×2 + 1nF 差模, fc≈8MHz]──► SP/SN（DRV8701 内置 ×20）
                                          │
 SO ──[3.3kΩ + 10nF, fc≈4.8kHz]──► MCU ADC（采样周期 239.5 cycles）
                                          │
 VREF ◄──[100nF 去耦]── MCU DAC（软件可调限流阈值）

5.2 输出级 RC（ADC 前最后一关）

  • 取值：3.3kΩ + 10nF C0G → fc ≈ 4.8kHz。
    • 依据：fc ≤ PWM(17kHz)/3，且 ≥ 电流环带宽(1–2kHz) 的 2–3 倍，两头兼顾。
    • 对 17kHz 基波纹波衰减 ≈ 11dB；残余纹波由下管导通中点同步采样从时序上消除（17kHz、L≈100µH 时纹波高达 ~1.3A pp，不同步采样必然翻车）。
  • 摆放：3.3kΩ 靠近 SO 引脚（隔离芯片输出与容性负载），10nF 紧靠 MCU 的 ADC 引脚且地脚落逻辑地——它同时是 ADC 采样保持的"电荷桶"。
  • ADC 配置：采样周期 239.5 cycles（3.3kΩ 源阻抗 + 10nF 下保证建立精度）；开启 16× 硬件过采样 → 有效约 14 bit。

5.3 输入级差模滤波（SP/SN 前）

  • 10Ω ×2 串入 SP、SN，1nF 跨接在两电阻芯片侧之间 → 差模 fc ≈ 1/(2π·20Ω·1nF) ≈ 8MHz，专杀换向火花耦合进来的射频噪声，对 72–144mV 的直流信号零影响。
  • 可加 100pF ×2 共模电容到逻辑地；低侧采样共模电压低，非必需。
  • 电阻串在芯片侧还是电阻侧？电阻靠 Rsense 侧、电容靠芯片侧，让电容就近为 SP/SN 提供低阻抗。

5.4 电机端源头吸收（性价比最高的 EMI 手段）

  • 电机引脚间 100nF C0G ×1 + 每引脚对外壳 100nF ×2，直接焊在电机端子上，引线越短越好。
  • 电机线双绞，必要时线上套磁环；电源入口串磁珠（600Ω@100MHz）隔离功率板与逻辑供电。
  • 9V 母线入口：SMBJ12A TVS 吸收制动回灌尖峰，方向朝 GND，紧贴输入端子。

5.5 VREF 与逻辑电源

  • VREF 由 MCU DAC 输出：串 100Ω + 并 100nF 到逻辑地，滤掉 DAC 台阶噪声，避免限流阈值抖动。
  • DRV8701 的 VM 去耦与逻辑 3.3V 去耦（100nF + 10µF）各自独立，不要共用同一段地回路。

6. 17kHz 专属检查项

  1. 栅极驱动强度（IDRIVE）：17kHz 开关损耗 = ½·V·I·(tr+tf)·f，AON6244 Qg 约 40nC。IDRIVE 先设 ~100/200mA 档，示波器看 SH 上升沿：目标 tr ≈ 100–300ns——太快 EMI 炸，太慢开关损耗大。边沿抖动不要靠 RC 去压，调 IDRIVE。
  2. 死区：DRV8701 内部自带 VGS 监控防直通，MCU 侧无需额外死区，但 PWM 最小占空比仍要 ≥5%（保证低侧采样窗口 2.9µs）。
  3. 同步采样时序：TIM 中心对齐模式，TRGO 在下管导通中点触发 ADC 注入转换；避开边沿后 ~1µs 振铃期。
  4. 斩波频率注意：DRV8701 限流采用固定关断时间斩波（t_off 约 25µs 量级），限流激活时 SO 上会出现 ~40kHz 纹波——已被 4.8kHz RC + 同步采样双重压制，无需额外处理。

💡 一句话总结：把高 di/dt 电流关在功率区的小环里（贴身电容 + 星型地），把 mV 级采样信号用 Kelvin 差分对护送出去（8MHz 差模滤波），出 SO 后按 4.8kHz 收尾交给 ADC——剩下的交给下管中点同步采样和软件过采样。布局对了，滤波才有意义；布局错了，再多电容也救不回来。
